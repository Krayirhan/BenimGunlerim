# Project Purpose — RUN-001-BASELINE

## Primary purpose

Help one person calmly plan daily tasks and routines, retain their local history, and see motivating progress.

## Primary user promises

- Tasks, routines, completion history and preferences are not unexpectedly lost.
- Daily completion, streak/progression and reminders behave consistently.
- The Turkish interface is understandable and usable with accessible controls.
- Export/import and data clearing behave predictably.

## Failure consequences

Primary consequences are personal productivity disruption, local-data loss, accidental cloud-backup disclosure, incorrect progress, and missed reminders. No financial, account takeover, tenant-isolation, or server availability consequence was found.

## Non-goals

Cloud sync, user accounts, backend authorization, multi-tenancy, payments, regulated-health handling, distributed observability and horizontal scaling are out of scope.
